# Product Management System

A mini  Product Management System built with a clean structure and using php OOp concepts with authentication system.  
This project demonstrates core php concepts na oop skills like authentication, CRUD operations, searching, sorting, and protected routes.

---

## 🚀 Key Features

- ✅ User Registration with hash password
- ✅ Secure Login & Logout  
- ✅ Authentication  (User must be logged in to access dashboard and other protected pages)  
- ✅ Clean Product Listing  
- ✅ Add, Edit & Delete Products 
- ✅ Search Products by Keywords  
- ✅ Sort Products by:
  - Creation Date
  - price high to low
  - price low to high 
  - Price  
  - Status  


## 🛠 Technologies Used

- PHP (Vanilla PHP)
- MySQL
- HTML / CSS /SCSS 

---

## 🔐 Authentication Flow

- User registers an account
- User logs in securely
- Session is created
- Unauthorized users cannot access dashboard or protected pages
- User can logout safely
- if the user is logged in they cannot access the register and login page until logout
